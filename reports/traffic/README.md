# 网站访问汇总（尚未启用）

公开报告尚未启用，这里没有历史访问数字，也没有生成示例计数。

部署并验证仅提供汇总数据的 Cloudflare Worker 后，可将 GitHub 仓库变量 ANALYTICS_PUBLIC_REPORT_ENABLED 设为 true。报告工作流计划每小时第 23 分钟运行，也可手动触发；GitHub 调度可能延迟。

启用后，本目录仅发布 summary.json 和本说明页：最近 30 天每日页面浏览量、最近 7 个日历日已结束小时的页面浏览量，以及前 30 个完整日历日的国家/美国州/城市粗粒度汇总。页面浏览次数不是独立访客人数。

地理位置来自近似 IP 定位。地区单元少于 5 次时不公开，其余计数向下取整至 5 的倍数，每类最多 100 项。未知位置不公开，未列出的地区不表示访问量为零。

启用后，0 表示没有记录到页面浏览，包括尚未开始采集的日期，不证明当时没有实际访客。开始采集之前的历史流量无法恢复。

不公开个人访问时间、访问明细、访客标识、IP 地址、县级位置或地区与时间的交叉表。公开报告无需密码或登录。

抓取失败、接口未就绪或数据格式不完整时，工作流会失败并保留上次成功报告，不会用零值替代缺失数据。
